# 담당자 질문 · 꼬리 질문 · 역제안 · 옵션화

담당자(사람, 담당자 페르소나 챗봇, 출제자 채널)와의 대화는 기록에 남고 평가된다. 판단력이 보이게 만든다. 질문 초안을 제시하거나, 사용자의 초안이나 담당자의 답을 받아 다듬는다. 보낼지와 무엇을 보낼지는 사용자가 정한다.

## 담당자가 애매하게 말할 때의 전제

- **숨은 조건은 꼬리 질문에서 나온다.** 첫 답은 "있으면 좋고요", "너무 많지만 않게" 같은 미지근한 말이 많다. 과제 설명에 문제와 해법이 적혀 있어도 대화에서만 나오는 조건이 있다.
- **톤을 기록한다**(값은 SKILL.md 공통 용어).
- **모든 조건이 미지근하면 무엇이 가장 아픈지 묻는다.**
- **끝내 정하지 않으면 사용자가 정하고 동의를 받는다**(역제안·옵션화). 동의 문장을 원문 그대로 남겨야 "합의했다"가 된다.

## 발굴 질문 (대화 초반, 해법 단어 없이)

처음 몇 개 질문에는 사용자가 생각한 해법 단어("군집화", "대시보드", "자동화")를 쓰지 않는다.

```text
최근에 이 문제 때문에 실제로 곤란했던 일이 있었나요?        (사례)
지금은 그걸 어떻게 처리하고 계세요?                         (우회책)
얼마나 자주, 얼마나 큰 손해인가요? 지금 값은 얼마인가요?     (정량화)
누가 불편을 겪고, 누가 결정하나요?                          (당사자)
이번에 다루지 않아도 되는 건 뭔가요?                        (경계)
```

## 확인 질문

- **질문 하나 = 결정 하나.**
- 수치를 물을 땐 "어기면 어떤 일이 생기나"를 같이 묻는다.

```text
[관련: R3] "원문 구절"이라고 되어 있는데, A(구체적으로)로 이해했습니다.
B(구체적으로)일 가능성도 있어 확인드립니다. A가 맞을까요?
```

## 꼬리 질문

담당자 답에서 아직 정해지지 않은 것을 짚고 다음 질문 후보를 1~3개 준다. 사다리:

```text
1 필수 여부  말씀하신 "___"는 반드시 지켜야 하나요, 있으면 좋은 정도인가요?
2 우선순위    그게 지금 가장 큰 고민인가요? 아니면 더 큰 게 있나요?
3 수치·실패  어디서부터 문제로 보시나요? 넘으면 무슨 일이 생기나요?
4 충돌        ___를 지키면 ___가 늘어납니다. 둘 중 어느 쪽을 우선할까요?
5 예외        기준에 안 맞는 경우(예: 정류장이 먼 사람)는 빼나요, 그대로 두나요?
6 이후        이 데이터는 실제로 어디서 오나요? 만든 뒤에는 누가 유지하나요?
```

6번 답은 합의문의 "세 가지 왜"(`agreement.md`) 재료다.

## 역제안

방향은 사용자가 정한다. 사용자가 방향을 정하지 않았으면 선택지 2~3개와 추천 하나를 이유와 함께 내고, 고른 방향을 문장으로 다듬는다.

```text
[관련: R3] 말씀 주신 "___"를 고려해 A(무엇을, 왜)로 진행하려고 합니다.
이렇게 하면 ___는 좋아지고 ___는 감수합니다. 이 방향으로 진행해도 될까요?
```

## 옵션화

```text
[관련: C3] 기준을 하나로 정하기 어려우시면 ___를 직접 고르실 수 있게 하고,
기본값은 ___로 두겠습니다. 괜찮을까요?
```

## 수용 확인 (단계 6)

합의한 성공 기준별 결과를 보여 주고 수용 여부를 묻는다. 결과 수치는 `REPORT`나 증거 칸에 있는 실제 측정값만 쓴다.

```text
합의문 기준 1(___)은 ___, 기준 2(___)는 ___입니다. [남은 한계: ___]
이 결과로 수용해 주실 수 있을까요? 바꿔야 할 점이 있으면 알려 주세요.
```

- 담당자가 **새 요청**을 꺼내면 바로 받지 않는다. 기능 동결 시각과 남은 시간을 보고 사용자가 정한다. 범위 밖으로 정하면 결정 로그에 "범위"로 남기고, 이렇게 답한다: "말씀하신 ___는 이번 범위에 넣지 못했습니다. 다음 단계로 제안드리고 인계 문서의 남은 한계에 적어 두겠습니다."
- 수용 문장은 합의 표에 원문 그대로 남긴다. 이것이 단계 6의 증거다.

## 답을 받은 뒤

- 질문과 답은 하나도 빠짐없이 담당자 질문 표에, 동의 문장은 합의 표에 남긴다(형식: `records.md`). 답은 대화 내역에 따라 달라지므로 기록이 판단의 증거다.
- 답을 받지 못하면 가정 표로 넘긴다.
