# 기록 — REQUIREMENTS.md 유지

## 제출 문서로 옮기는 법

| 제출 문서 항목 | 가져올 곳 |
|---|---|
| 문제 정의와 성공 기준 | 합의문 |
| 판단과 근거 | 요구사항 표의 "근거 한 문장" + 결정 로그(의도 변경 포함) |
| 담당자와 합의한 사항 | 합의 표 |
| 가정 사항 | 가정 표 |
| 남은 한계 | 상태가 "가정"·"범위 밖"인 항목 + 가정 표의 "틀렸을 때 영향" + 합의 표의 "남는 한계" |
| 인계 | HANDOFF.md (단계 7에 제출용 절까지 채운 것) |
